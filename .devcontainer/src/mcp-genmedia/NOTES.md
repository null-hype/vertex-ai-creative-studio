# Developer Notes for mcp-genmedia Feature

## Implementation Details

The feature builds the MCP servers from source by cloning the repository into a temporary directory during the installation phase. This ensures that the servers are built for the target architecture of the container.

The binaries are installed to `/usr/local/bin` to be globally accessible.

The Gemini CLI is installed via npm and configured at `~/.gemini/settings.json`.

## Testing

You can run the feature tests using the DevContainer CLI:

```bash
# Run default tests
devcontainer features test --skip-scenarios -f mcp-genmedia .devcontainer

# Run scenario tests
devcontainer features test -f mcp-genmedia --skip-autogenerated --skip-duplicated .devcontainer
```

## Smoke Test Steps

1. Start the DevContainer.
2. Verify Gemini CLI is installed: `gemini --version`
3. Verify MCP servers are configured: `jq '.mcpServers' ~/.gemini/settings.json`
4. Run a basic tool list command:
   ```bash
   echo '{"jsonrpc":"2.0","method":"tools/list","id":1}' | mcp-avtool-go | jq .
   ```
5. (Optional) If you have a `PROJECT_ID` and API key, you can run:
   ```bash
   gemini "list my mcp tools"
   ```

## Profiles

The default profile only installs `avtool` to keep the installation minimal.
To install all tools, set `installAll` to `true`.
